# Kosmos

**Wallpapers in Motion.**

Kosmos is a privacy-first, offline-first Android wallpaper app for static images and live wallpapers.

## Product goals

- Curated built-in wallpaper presets and an optional online catalogue.
- Import and apply JPG, PNG, WebP, MP4, and GIF wallpapers.
- Preview before applying.
- Apply static wallpapers to the home screen, lock screen, or both where Android supports it.
- Use Android's native live-wallpaper confirmation flow for animated wallpapers.
- Keep downloaded media available offline.
- Pause rendering and release playback resources when the wallpaper is not visible.
- No account, advertising SDK, analytics, or unnecessary permissions.

## Technology

- Kotlin
- Jetpack Compose
- AndroidX Media3
- Android WallpaperManager / WallpaperService
- Room and DataStore (planned)
- WorkManager (planned for persistent downloads)

## Project status

The repository is being initialized. The first milestone focuses on the Android application foundation and static wallpaper flow. Live playback, local library persistence, and the remote catalogue will be added in subsequent milestones.

## Build

Open the project in the latest stable Android Studio and sync Gradle. The project uses the Gradle wrapper once generated by Android Studio.

## Privacy

Kosmos is designed to work without an account. Imported and downloaded media is stored in app-private storage by default. The online catalogue is optional; previously downloaded wallpapers remain available offline.
